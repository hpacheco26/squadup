# Internationalization

Source: [src/i18n](../src/i18n).

## API

```js
import { t } from './i18n';
t('en', 'squadUp');                      // → "Squad Up"
t('pt', 'joinSquadMessage', { group });  // params replace {group}
```

In React components, prefer the language store:
```js
const { t } = useLanguageStore();
t('squadUp');
```

## Adding a key

1. Add `myKey: 'English text'` to [src/i18n/en.js](../src/i18n/en.js).
2. Add the equivalent in [src/i18n/pt.js](../src/i18n/pt.js).
3. Use `{name}` placeholders for runtime substitution.

## Fallback rules

- Missing key in current lang → falls back to `en`.
- Missing in both → returns the key itself (visible reminder to translate).

## Storage

Selected language is persisted to `localStorage` under `squadup-lang`.
